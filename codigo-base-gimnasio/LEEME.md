# Código base · El gimnasio (Prácticas 15 a 18)

Es un solo código base para las cuatro prácticas. En cada práctica se toma **sólo la carpeta
de esa práctica**. Lo de las anteriores ya está en tu proyecto.

Antes de la Práctica 15 tiene que estar corriendo **`gimnasio-backend`**, siguiendo su
`README.md`, en `http://localhost:3000`.

## Práctica 15 · Rutas y layout

| Copia | A `gimnasio-web/` |
|---|---|
| `index.css` | `src/index.css` (reemplaza el de Vite) |
| `tipos.ts` | `src/tipos.ts` (ya trae los tipos de las cuatro prácticas) |
| `logo.svg` | `public/logo.svg` |
| `servicios/` | `src/servicios/` (`api.ts` y `gimnasio.ts`) |
| `hooks/useClases.ts` | `src/hooks/useClases.ts` |
| `componentes/` | `src/componentes/` (`Layout`, `Encabezado`, `PiePagina`, `Cargando`, `MensajeError`, `NoEncontrado`) |
| `html/` | se queda aquí: de ahí se copia el marcado de cada página |
